# Поиск максимума в большом слайсе

Консольная программа на Go. Она находит наибольшее число в одном и том же слайсе двумя способами: последовательным перебором и параллельно в восьми горутинах.

## Запуск

### 1. Установить Go

Скачайте Go версии 1.24.1 или новее с сайта <https://go.dev/dl/>. Проверьте установку:

```bash
go version
```

### 2. Запустить программу

Откройте терминал в папке с файлом `go.mod` и выполните:

```bash
go run .
```

Вводить данные не нужно: программа сама генерирует 100 миллионов случайных положительных чисел. Для каждого способа она выводит найденный максимум и время поиска в микросекундах. Время генерации в замер не входит.

## Как работает поиск

- При последовательном поиске программа проходит по слайсу от начала до конца и запоминает наибольшее число.
- При параллельном поиске каждая горутина находит максимум в своей части слайса. Если длина не делится на восемь, оставшиеся элементы попадают в последнюю часть. Программа ждёт завершения всех горутин и выбирает наибольший из восьми результатов.
- Если элементов меньше восьми, поиск выполняется без горутин. Для пустого слайса результат — `0`.

## Тестирование проекта

Чтобы запустить тесты, выполните в той же папке:

```bash
go test -v ./...
```

Чтобы дополнительно проверить параллельный поиск на гонки данных:

```bash
go test -race ./...
```
